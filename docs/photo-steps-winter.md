# Winter photo tutorial sheets

Created 2026-11-23 for the 75-second photo tutorials. These assets supplement the unchanged activity galleries. The built-in image generation tool produced all three originals; no external API or CLI image generator was used.

## Delivery and layout

Each sheet is an exact 3-column × 2-row grid, read left to right across the top row and then the bottom row. Panel 1 is materials/setup; panels 2–6 correspond to the five current catalogue steps. Original and WebP dimensions are **1881 × 836**, giving **627 × 418** landscape panels. The native resolution was retained without artificial upscaling, cropping, compositing, or creative post-processing. WebPs use quality 94, method 6.
